# Apna Bazaar

React frontend and Django backend prepared for Render.

Open [DEPLOYMENT.md](DEPLOYMENT.md) for free-tier setup, required environment values, persistent database and photo storage, and initial admin account setup.

The app uses Render for the web service, Neon PostgreSQL for durable records, Cloudinary for uploaded photos, and Resend's API for password reset emails. Add your own service credentials in Render; none are stored in this project.
